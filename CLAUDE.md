# Project Guidelines

## Planning (superpowers skills: writing-plans, brainstorming, executing-plans)

- When using superpowers planning skills, do NOT write the resulting design docs or implementation plans to markdown files by default.
- Plans may be shared in the chat window for review.
- Only write plans to a `.md` file if:
  - The user explicitly asks for it, or
  - The task is complex enough that a persistent written plan is genuinely necessary for safe execution.
